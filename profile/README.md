Research records here are public from their first commit. Each one works from primary sources

### How to read these repositories

- **History is never rewritten.** A correction is a new commit that says what it corrects and why.
- **Timing is independently checkable.** Pre-registrations are anchored with
  [OpenTimestamps](https://opentimestamps.org), so their dates don't depend on trusting GitHub.
- **Anything withheld is disclosed** — by name, or by count where the name itself would expose
  private work — never silently dropped.
- **AI assistance:** this work is done with Claude (Anthropic) as an AI collaborator. Authorship
  and responsibility for every claim are mine.

### Critique, not contribution

Issues that point out a flaw — in a prediction, a method, a source reading, or code — are welcome,
and are the adversarial inspection this work depends on. Pull requests are not accepted. See
[CONTRIBUTING](https://github.com/ericgray-research/.github/blob/main/CONTRIBUTING.md) and
[SECURITY](https://github.com/ericgray-research/.github/blob/main/SECURITY.md).
