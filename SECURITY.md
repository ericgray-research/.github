# Security policy

## Reporting a vulnerability

Report it **privately**: open the repository's **Security** tab and choose **Report a vulnerability**.
Please do not open a public issue, pull request, or discussion about it.

Include what is affected (repository, file, commit), how to reproduce it, and what an attacker could
do with it.

## What to expect

This is one person's work, so there is no guaranteed response time. Reports are read and acted on as
promptly as I can, and a confirmed vulnerability is fixed before anything about it is made public.
Once fixed, the fix and its cause are recorded in the repository's history like any other correction.
Tell me in the report if you want to be credited.

## Scope

Code in this organization's repositories. A flaw in a research claim or method is not a security
issue — please raise it as an ordinary issue (see [CONTRIBUTING.md](CONTRIBUTING.md)).
